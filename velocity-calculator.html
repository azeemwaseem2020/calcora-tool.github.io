Calculate average velocity from distance and time

Velocity formula

For this basic calculator, average velocity magnitude is calculated as v = d ÷ t, where d is distance and t is elapsed time. With metres and seconds, the result is metres per second (m/s).

How to calculate average velocity

  1. Enter the distance travelled.
  2. Enter the elapsed time.
  3. Keep the distance and time units consistent.
  4. Divide distance by time.
  5. Report the result with its unit.

Worked example

If an object travels 100 m in 10 s, v = 100 ÷ 10 = 10 m/s.

Velocity vs speed

Velocity is a vector quantity, so true velocity includes direction. Speed describes only how fast something moves. This simple tool calculates the average velocity magnitude from distance and elapsed time; it does not accept direction.

Unit consistency

If distance is in kilometres and time is in hours, the result is km/h. Convert the inputs when you need a different unit such as m/s.

Common mistakes

  • Dividing by zero or entering a negative time.
  • Mixing kilometres with seconds without converting units.
  • Calling a distance-over-time result instantaneous velocity when motion is changing.
  • Ignoring direction when a vector velocity is required.

When to use this calculator

Use it for introductory physics, motion problems, classroom exercises and simple average-rate calculations when distance and elapsed time are known.

Important limitation

This tool is intended for simple average velocity magnitude calculations. It does not model acceleration, instantaneous velocity, changing direction or detailed motion over time.
