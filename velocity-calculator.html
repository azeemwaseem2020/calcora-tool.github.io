Velocity Calculator

Calculate average velocity magnitude from distance and elapsed time.

Enter distance and time

Velocity formula

For this basic calculator, the average velocity magnitude is calculated as v = d ÷ t, where d is distance and t is elapsed time. With metres and seconds, the result is metres per second (m/s).

Worked example

If an object travels 100 m in 10 s, v = 100 ÷ 10 = 10 m/s.

How to use the calculator

  1. Enter the distance travelled in metres.
  2. Enter elapsed time in seconds.
  3. Choose Calculate Velocity.
  4. Review the result and calculation steps.

Velocity vs speed

Velocity is a vector quantity, so true velocity includes direction. Speed describes only how fast something moves. This simple tool calculates the average velocity magnitude from distance and elapsed time and does not accept direction or changing motion.

Unit consistency

Keep units consistent. For example, if distance is in kilometres and time is in hours, the result is km/h. Convert units when you need a result in m/s.

Limitations

This tool is intended for simple average calculations. It does not model acceleration, instantaneous velocity, changing direction or detailed motion over time.
