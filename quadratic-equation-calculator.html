Quadratic Equation Calculator

Solve ax² + bx + c = 0 and see the discriminant and working used to find the roots.

Enter coefficients

Formula

x = (-b ± √(b² − 4ac)) ÷ 2a

How it works

  1. Calculate the discriminant D = b² − 4ac.
  2. If D is positive, there are two real roots.
  3. If D is zero, there is one repeated real root.
  4. If D is negative, the equation has complex roots.

Example

For x² − 5x + 6 = 0, the roots are 2 and 3.
