Average Calculator

Find the arithmetic average (mean), total and count of multiple numbers. Enter values separated by commas or spaces and get the result with the calculation shown.

How to calculate an average

Add all the values together, then divide the total by the number of values. The result is the arithmetic mean.

Average formula

Average = Sum of all values ÷ Number of values

Worked example

For 10, 20 and 30, the sum is 60 and the count is 3, so the average is 60 ÷ 3 = 20.

When to use an average

The arithmetic mean is useful for test scores, prices, measurements, sales figures, response times and other numerical data when a single representative value is needed.

Average vs median

The mean can be affected by unusually high or low values. If your data is heavily skewed, comparing the average with the median can provide a more useful view of the dataset.

Common mistakes

  • Dividing the sum by the wrong number of values.
  • Accidentally leaving out a value from the total.
  • Mixing values that should use different units without converting them first.

What this calculator does

This tool calculates the arithmetic mean, sum and count from the numbers you enter. It does not calculate weighted averages or automatically remove outliers.
