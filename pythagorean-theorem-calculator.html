Pythagorean Theorem Calculator

Find the hypotenuse or a missing leg of a right triangle and see the calculation steps.

Formula

For a right triangle, a² + b² = c², where c is the hypotenuse. If the hypotenuse is unknown, c = √(a² + b²). If a leg is unknown, a = √(c² − b²).

Worked example

For legs 3 and 4: 3² + 4² = 9 + 16 = 25, so c = √25 = 5.

Calculation steps

  1. Identify the two known sides.
  2. Square the known values.
  3. Add squares for a missing hypotenuse, or subtract a leg square from the hypotenuse square when solving for a leg.
  4. Take the square root and check that the result is physically valid for a right triangle.

When to use it

This tool is useful for right-triangle geometry, construction measurements, school mathematics and distance calculations where two perpendicular components form a right triangle.

Limitations

The calculation assumes a right triangle. It does not solve general triangles; use a suitable law of sines or law of cosines method for those cases.
